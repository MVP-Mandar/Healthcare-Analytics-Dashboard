# Healthcare-Analytics-Dashboard – Power BI

An interactive **Healthcare Analysis Dashboard built with Power BI**, analyzing **55,500 patient records from 10 major U.S. hospitals between 2019 and 2024** to uncover healthcare trends, patient demographics, hospital performance, and treatment insights.

## 📊 Project Overview

The dashboard provides an interactive view of patient and hospital data across **three pages: Overview, Demographics, and Insights**.

### 🔍 Dashboard Highlights

* 📌 **55,500 patient records** analyzed across **10 U.S. hospitals**
* 💰 Analysis of **total billing and treatment costs**
* 🏥 Hospital-wise and **state-level admission analysis**
* 🩺 Identification of **most common medical conditions**
* 👥 Patient breakdown by **age and gender**
* 🩸 Analysis of **blood type distribution**
* 💊 Insights into **drug usage and treatment patterns**
* 🎛️ Interactive **slicers, bookmarks, and navigation buttons**
* 📈 Dynamic visualizations for exploring healthcare trends and patterns

## 📑 Dashboard Pages

### 1. Overview

Provides a high-level summary of patient counts, billing amounts, hospital admissions, and common medical conditions.

### 2. Demographics

Analyzes patient demographics including age groups, gender, and blood type distribution.

### 3. Insights

Provides deeper analysis of hospital admissions, treatment costs, state-wise trends, and medication/drug data.

## 🛠️ Tools & Technologies

## 🎯 Project Objective

The objective of this project is to transform raw healthcare data into meaningful and interactive visual insights that can help identify **patient trends, hospital patterns, treatment costs, and healthcare outcomes**.

This project demonstrates practical skills in **data cleaning, data modeling, DAX, visualization, and dashboard development using Power BI**.
